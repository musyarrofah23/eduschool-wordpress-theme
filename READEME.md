# EduSchool WordPress Theme

**EduSchool** adalah tema WordPress untuk website profil SMP Informatika Roudlotul Hidayah (SMP Ifrah), yang berlokasi di Kecamatan Kwanyar, Kabupaten Bangkalan, Jawa Timur.

## Fitur

- Halaman beranda dengan ilustrasi gedung sekolah.
- Halaman profil sekolah.
- Halaman fasilitas sekolah.
- Daftar berita dan kegiatan sekolah.
- Halaman detail artikel.
- Navigasi menu utama.
- Sidebar pada halaman artikel.
- Desain responsif untuk desktop dan perangkat seluler.
- Dukungan gambar unggulan artikel.
- Dibangun menggunakan PHP, HTML, CSS, dan fungsi WordPress.

## Teknologi

- WordPress
- PHP
- HTML
- CSS

## Instalasi

1. Salin folder `eduschool` ke direktori `wp-content/themes/` pada instalasi WordPress.
2. Masuk ke dashboard WordPress.
3. Buka menu **Tampilan → Tema**.
4. Aktifkan tema **EduSchool**.
5. Atur menu utama melalui **Tampilan → Menu**.
6. Buat halaman dan artikel sesuai kebutuhan website.
